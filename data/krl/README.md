# KRL timetable data

This directory contains a historical snapshot of KRL timetable data, not a live or current departure board. The latest source-record timestamp is **2026-10-06T01:44:49Z UTC** ( **2026-10-06 08:44 WIB** ); source records span 2026-08-29 through 2026-10-06. The snapshot was retrieved on 2026-10-15T08:06:29Z. Ten Jabodetabek station boards had no compatible KRL departures in the source snapshot and are marked unavailable. Airport Rail Link rows and stations outside the app's Jabodetabek KRL network are not included in the timetable.
